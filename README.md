# Converter Studio for Homebrew

[Converter Studio](https://converter.studio/) converts video, audio, images, PDFs and documents on your
computer. This tap installs the macOS app (a universal DMG, signed and notarized by Apple) and the
`converter-studio` command.

```sh
brew install --cask tariksucu/tap/converter-studio
```

Update with `brew upgrade --cask converter-studio`; the app also tells you when a new version is out.

- Download page: <https://converter.studio/download>
- Help: <https://converter.studio/support>

The cask only points to the DMG on converter.studio; the app itself is not in this repository.
